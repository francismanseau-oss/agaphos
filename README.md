# Agaphos

Unis par l’amour, guidés par la lumière.

Site fondation (pages statiques) : trois piliers **Unir** · **Éclairer** · **Agir**, charte des 12 Lumières, bibliothèque spirituelle.

## Développement local

Ouvrir `index.html` ou servir le dossier :

```bash
npx --yes serve .
```

Régénérer les pages Éclairer depuis les textes Desktop :

```bash
node scripts/build-site.mjs
```

## Publication

GitHub Pages — dépôt `francismanseau-oss/agaphos` (branche `main`, racine `/`).
